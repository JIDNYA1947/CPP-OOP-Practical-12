# Practical No. 12: Type Casting and Casting Operators

## Aim
To implement type casting and casting operators in C++.

## Theory
Type casting is the process of converting a value from one data type to another.

There are two types of type casting:
1. **Implicit Casting:** Conversion performed automatically by the compiler.
2. **Explicit Casting:** Conversion performed manually by the programmer.

C++ provides four casting operators:
- `static_cast`: Used for normal type conversions.
- `dynamic_cast`: Used for safe conversion between related class pointers.
- `const_cast`: Used to add or remove the `const` qualifier.
- `reinterpret_cast`: Used for low-level conversions between pointers and other types.

## About
This practical demonstrates type casting and casting operators in C++. It covers implicit casting, explicit casting, static_cast, dynamic_cast, const_cast, and reinterpret_cast using a Student Result Management System example. It helps to understand how values and pointers can be converted from one type to another in C++.
